Connect GitHub Repository

Embed live Giscus or Utterances comments

To link live GitHub issues/discussions to your site so comments persist directly on GitHub, follow these 2 steps:

Option 1: Using Giscus (Recommended)

  1. Enable Discussions in your public GitHub Repository settings.
  2. Install the Giscus GitHub App on your repository.
  3. Copy the generated script tag from giscus.app.

Generated Script Snippet Example:

<script src="https://giscus.app/client.js"
        data-repo="[your-username]/[your-repo]"
        data-repo-id="R_kgDO..."
        data-category="Announcements"
        data-mapping="pathname"
        data-theme="light"
        crossorigin="anonymous"
        async>
</script>
